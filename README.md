# Лабораторная работа №3 —

## Стек
- Python + Flask
- PostgreSQL 17
- psycopg2

## Структура
- `app.py` — маршруты Flask
- `db.py` — подключение к БД
- `templates/` — HTML-шаблоны
- `static/style.css` — стили
- `sql/lab3.sql` — дамп БД (схема + функции + данные)

## Запуск
1. Создать БД: `psql -U postgres -f sql/lab3.sql`
2. `pip install -r requirements.txt`
3. Заполнить `.env` (см. `.env.example`)
4. `python app.py`
5. Открыть http://127.0.0.1:5000

## Функционал
- Формы ввода: начисления, платежи, сальдо
- Отчёты (на хранимых функциях):
  - оборотная ведомость
  - оборотная ведомость по квартире
  - сводка по должникам
